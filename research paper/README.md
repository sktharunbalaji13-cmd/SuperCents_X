# Algorithmic Trading Structure — Research Papers

This folder collects real, **freely-downloadable (open-access)** academic papers that describe the mathematics and evidence behind the classic **retail / Smart Money Concepts (SMC)** trading structures used in this project (SuperCents_X).

> **Important note:** `BOS`, `CHoCH`, `Order Blocks`, `Fair Value Gaps`, `Liquidity Sweeps` and `SMC` are **retail-trading vocabulary** popularised by ICT, **not** formal terms in peer-reviewed literature. Each subfolder therefore maps the retail structure to its closest **academic equivalent** (support/resistance & breakouts, turning points & trend-following, change-point/regime detection, order flow & order book, price gaps/imbalance, market liquidity, and informed/institutional flow) and contains real papers on that underlying science. All PDFs were downloaded from **arXiv** (open access) and verified to be valid PDF files.

## Folder map
| Folder | Retail structure | Academic equivalent |
|---|---|---|
| `bos/` | **Break of Structure** (trend continuation) | Support/resistance breaks, breakout & self-fulfilling behaviour |
| `swing/` | **Swing points / swing trading** | Local extrema, short-term technical analysis, trend following |
| `choch/` | **Change of Character / MSS** (reversal signal) | Change-point & regime-switching detection |
| `ob/` | **Order Block** (institutional footprint zone) | Order flow, order book, order flow imbalance |
| `fvg/` | **Fair Value Gap / imbalance** | Price gaps & market-depth imbalance |
| `liquidity/` | **Liquidity sweep / stop hunt** | Market liquidity measurement & order-book dynamics |
| `smc/` | **Smart Money Concepts** (umbrella) | Market microstructure, informed trading & adverse selection |

**28 papers total** — `bos/` 3, `swing/` 4, `choch/` 5, `ob/` 5, `fvg/` 3, `liquidity/` 4, `smc/` 4. All PDFs were downloaded from **arXiv** (open access), verified valid, and each subfolder's `README.md` explains the structure and how the papers relate to it.
